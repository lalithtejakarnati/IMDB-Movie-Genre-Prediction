# 🎬 IMDB Movie Data Analysis and NLP-Based Genre Prediction

## Overview

This project explores the IMDB Movie Dataset using Data Analysis, Visualization, Natural Language Processing (NLP), and Machine Learning concepts.

The objective is to analyze movie trends, ratings, revenue, voting patterns, director performance, and genre distributions while establishing a foundation for automated movie genre prediction using text classification techniques.

---

## Key Features

- Data Cleaning and Preprocessing
- Missing Value Analysis
- Exploratory Data Analysis (EDA)
- Statistical Data Insights
- Revenue Trend Analysis
- Movie Rating Analysis
- Director Performance Evaluation
- Genre-Based Analysis
- NLP-Based Text Processing
- Movie Classification Foundations

---

## Dataset Information

The dataset contains information about 1,000 IMDB movies.

### Features

| Column | Description |
|----------|-------------|
| Rank | Movie Rank |
| Title | Movie Name |
| Genre | Movie Genre |
| Description | Movie Plot Summary |
| Director | Director Name |
| Actors | Cast Information |
| Year | Release Year |
| Runtime (Minutes) | Duration |
| Rating | IMDB Rating |
| Votes | User Votes |
| Revenue (Millions) | Revenue Generated |
| Metascore | Critic Score |
